# HTML & CSS for Beginners 🧑🏾‍💻 — by Code With Addo

Hands-on lesson files from my **HTML & CSS beginner class**. Each file is a small, working web page that teaches one idea. Open it in a browser, read the code, change it, break it, fix it — that's how you learn.

## 📚 Lessons

Work through them in this order:

| # | File | What you'll learn |
|---|------|-------------------|
| 1 | [`index.html`](index.html) | Page structure (`header`, `main`, `footer`), lists, a first registration form |
| 2 | [`forms.html`](forms.html) | Forms in depth — `label`, text & number inputs, `select`, radio buttons, `textarea`, `required` |
| 3 | [`simpleTables.html`](simpleTables.html) | Tables — `table`, `thead`, `tbody`, `tr`, `th`, `td` |
| 4 | [`meta.html`](meta.html) | Meta tags (charset, viewport, description, keywords) — a clean page template |
| 5 | [`divs.html`](divs.html) | `div` boxes and **inline CSS** (`style="..."`) |
| 6 | [`div2.html`](div2.html) | **Internal CSS** (`<style>` tag) — element selectors and `#id` selectors |
| 7 | [`externalcss.html`](externalcss.html) + [`css/styles.css`](css/styles.css) | **External CSS** (`<link>`) and `.class` selectors |

## 🚀 Getting started

**1. Fork this repo** — click **Fork** at the top right of this page. You now have your own copy.

**2. Clone your fork** to your computer:

```bash
git clone https://github.com/YOUR-USERNAME/html-css-beginners.git
cd html-css-beginners
```

**3. Open a lesson** — double-click any `.html` file to open it in your browser.
Tip: in VS Code, install the **Live Server** extension, right-click a file → *Open with Live Server*, and the page reloads every time you save.

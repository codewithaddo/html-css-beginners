# Student Workspace

This is where **your** practice work lives.

## How to add your folder

1. Create a folder named after your GitHub username, e.g. `students/janedoe/`
2. Put your exercise files inside it, e.g. `students/janedoe/index.html`
3. Commit, push to your fork, and open a pull request

```
students/
├── README.md
├── janedoe/
│   ├── index.html
│   └── css/
│       └── styles.css
└── your-username/
    └── index.html
```

## Rules
- Only edit files inside **your own** folder
- Use lowercase file names with no spaces (`about-me.html`, not `About Me.html`)
- Check your page in a browser before you push

> First exercise idea: build an **About Me** page using a heading, a paragraph, a list of your hobbies, a table of your weekly class schedule, and an external stylesheet.
